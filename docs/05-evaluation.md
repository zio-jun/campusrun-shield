## 3. 关键结论

1. **客户端单点检测可被绕过**：方式一可伪装 isMock，方式二可换 Build 字段；单点检测只是过滤器。
2. **壳完整性校验是实测有效的第一道硬门槛**：方式一必须先补丁校验调用，成本陡增。
3. **服务端交叉校验是决定性防线**：方式一无法伪造步频 → 步频×速度交叉必露馅；轨迹物理/环境一致性持续有效。
4. **方式二的暴露面更大**：模拟器指纹 + 设备认证可提前拦截，即使伪造传感器也难逃时间/轨迹聚类。
5. **人脸活体是共同硬边界**：两种方式都无法低成本绕过，是证据链的核心价值。
