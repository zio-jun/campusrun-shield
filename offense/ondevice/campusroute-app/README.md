# 校园路线

Android 8.0 及以上。App 内置华中科技大学主校区离线地图，支持设置起点、终点、途经点和速度。地图数据日期为 2026 年 11 月 17 日。

## 自定义地图（v1.1）

1. 地图加载顺序：用户导入的地图 > 内置华科地图 > 空白模式。
2. 点地图右上「空白地图」可在无底图模式下直接选点（浅色网格底图），画线、画圈、预览与系统定位输出均不受影响；空白模式首次选点会自动以其为投影原点。
3. 点地图左下「导入地图」通过系统文件选择器选取 GeoJSON（FeatureCollection/Feature，WGS84 经纬度，LineString/Polygon 等）或与 `campus-map.json` 同格式的 JSON（可带 `origin` 字段）。文件会复制到应用私有目录并立即生效；格式错误会提示且不覆盖原地图。
4. GeoJSON 的 LineString/MultiLineString 会自动转成步行路网，「沿道路」规划可用；要素 `properties.name` 会显示为地名标签。

## 设定路线

1. 依次在地图上点出起点和终点，也可用「坐标」填写 WGS84 纬度、经度。
2. 可按经过顺序添加途经点。起终点相同时，先加途经点即可规划环线。
3. 默认沿离线地图中的步行道路规划。找不到道路的路段会直连，界面会显示提示。输入速度（km/h），即可查看路线距离、配速和预计用时。
4. 点「预览」可在 App 内查看移动过程。

## 系统定位输出

1. 在 Android 开发者选项中进入「选择模拟位置信息应用」，选择「校园路线」。
2. 打开手机定位，在校园路线里点「准备系统定位」。首次使用时授权定位和通知，随后系统定位停在起点。
3. 可点右上角的「打开华中大体育」。准备好以后，从通知栏点「开始移动」。也可直接在校园路线内开始和停止。
4. 到达终点后，模拟定位会保留 60 秒。点「结束输出」可提前恢复系统定位。

Android 会把输出的位置标为模拟定位。「华中大体育」是否显示该轨迹，以及评分次数是否增加，仍需用对应版本和有效的校内账号验证。

## 构建

用 Android Studio 打开本项目，安装 Android SDK 35。命令行可用 JDK 17 或以上运行 `./gradlew assembleDebug`，产物位于 `app/build/outputs/apk/debug/`。

App 使用 Android 平台 API，地图和路线计算在本机运行。地图数据归 OpenStreetMap 贡献者所有，以 ODbL 1.0 发布，详见 `app/src/main/assets/MAP-NOTICE.txt`。`tools/prepare_map.py` 可把任意地区的 OSM XML 提取转换成可导入的 campus-map 格式。
