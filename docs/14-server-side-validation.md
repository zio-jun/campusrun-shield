# 14 · 服务端判定算法（终局防线）

> 客户端终究可被完全控制；成绩真伪的终局判定在服务端。
> 本文给出可落地的证据校验与轨迹形态学算法，配套实现见
> `defense/server-side/run_evidence_validator.py` 与 `trajectory_plausibility.py`。

## 1. 证据强制提交

- 提交成绩必须携带完整证据：轨迹点序列（lat/lng/时间戳/定位来源/精度/速度）+ 距离/用时字段。
- 服务端**不信任客户端汇总字段**：距离、平均配速、卡路里一律重算。
- 证据缺失/损坏 → 直接拒收（不降级、不默认放行）。

## 2. 距离重算与一致性校验

- 重算：Haversine/球面距离逐段累加，与上报里程比对，偏差 > 阈值（如 2%）即异常。
- 一致性方程组（全应近似成立）：
  - 里程 ≈ Σ 相邻点距离
  - 用时 ≈ 末点时间 − 首点时间
  - 平均速度 ≈ 里程 / 用时
  - 分段速度 ≈ 点间距 / 点时间差
  - 最大速度 ≤ 生理上限（如 10 m/s）
- 任何一组矛盾即标记。

## 3. 轨迹形态学特征（识别回放/匀速/画圈）

| 特征 | 真人形态 | 伪轨迹形态 |
|---|---|---|
| 点间距方差 | 随路况波动 | 过小（匀速生成）或过大（跳点） |
| 转角分布 | 平滑弧线（惯性） | 折角尖锐（直线拼接/画圈切角） |
| 速度序列自相关 | 步态节律（约 1–2 Hz 分量） | 无节律/白噪声/恒定 |
| 速度分布 | 类正态、有偏度 | 平顶（钳制）或双峰 |
| 停顿模式 | 偶发减速/短暂停顿 | 无停顿 |
| 贴路率 | 与路网高匹配 | 偏离道路/穿楼 |
| 轨迹重复度 | 历史轨迹间低相似 | 与历史/他人轨迹高度重合 |

实现要点：
1. 速度钳制检测：对速度序列做直方图，检查分布是否出现"上限平台"（如 2.2–4.2 m/s 钳制区间端点堆积）。
2. 熵估计：样本熵/排列熵，回放轨迹熵显著低于真人。
3. 重复检测：设备-账号维度对轨迹做 DTW/哈希相似度聚类，跨账号重复轨迹即代跑团伙信号。

## 4. 配速与生理模型

- 配速分段方差：真人 5k 分段配速波动通常 > 5%（非精英跑者）；方差过小即匀速模拟。
- 长距离匀速惩罚：> 3 km 且分段配速 CV < 2% → 可疑。
- 成绩曲线异常：无训练史账号突然满分；历史成绩分布突变。
- 可选：心率/步频数据（穿戴）与配速相关性校验。

## 5. 时间与位置一致性

- 上报时间戳与服务端接收时间差校验；
- 轨迹时间跨度与完成用时的 clock 漂移检查；
- 登录地 IP 与轨迹地理位置的合理性（跨省瞬移）。

## 6. 设备与账号图谱

- 一机多号 / 一号多机 图谱；
- 同 IP、同时段、同轨迹形态的批量完成 → 团伙聚类；
- root/模拟器/mock 设置命中标记的设备，成绩可信度降权（不直接拒绝，进入人工队列）。

## 7. 人工复核与惩罚梯度

- 命中 N 个异常特征 → 自动进入人工复核队列（轨迹可视化回放工具）；
- 惩罚梯度：警告 → 成绩作废 → 限时禁跑 → 拉黑设备/账号；
- 满分/冲刺成绩自动提高复核概率。

## 8. 与仓库代码对应

- `run_evidence_validator.py`：证据结构校验 + 距离重算 + 一致性方程组（§1、§2）。
- `trajectory_plausibility.py`：形态学特征 + 速度分布/熵/重复检测（§3、§4）。
- 扩展建议：把两类输出合并为风险评分（0–100），按分数分流自动通过/人工复核。
